# File Explorer

In a details view, each item is read with its columns: "report.docx, Date modified: 3/5/2026
10:12, Type: Word document, Size: 24 KB, 3 of 10". The name is said first, without its header;
empty columns are left out. Turn the headers off on the Applications page of the settings dialog
(*File Explorer: say column headers in details view*) to hear the values alone.

Items in other views (icons, tiles) and on the desktop keep their usual announcement. Explorer is
also the taskbar and Alt+Tab; only list items are changed.
