Vox user guide

Vox is a screen reader for Windows 11. It reads what is on the screen aloud, and lets you browse web pages, documents and applications from the keyboard.

Getting started

When Vox starts for the first time, a short welcome wizard asks how fast to speak, how much detail you want and which key to use as the Vox key. Run it again at any time from the Vox menu (Insert+N), or with Insert+Ctrl+S.

If you used NVDA or JAWS on this computer, the wizard offers to bring over your speech settings, your own keys and your dictionaries first, and shows a report of what it brought over and what it could not. Import settings from NVDA or JAWS in the Vox menu does the same at any time, showing the report before anything is changed. Vox keeps a copy of each of its own files it replaces.

To start Vox, press Ctrl+Alt+V (the installer sets up this key). To start it every time you sign in, check Start Vox when I sign in on the General page of the settings (Insert+Ctrl+G).

To quit Vox, press Insert+Q twice, or choose Exit Vox in the Vox menu. Ctrl stops speech at any time.

The Vox key

Most Vox commands are pressed with the Vox key held down: Insert, or Caps Lock if you chose it. Keys pressed with the Vox key are always Vox's: they never reach the application. To use the Vox key's own function (turn Caps Lock on, for example), press it twice quickly.

On a laptop without a numeric keypad, choose the laptop keyboard layout in Settings, Keyboard.

Learning the keys

  • Input help, Insert+1: while it is on, every key says what it does instead of doing it. Press Insert+1 again to turn it off.
  • Command search, in the Vox menu: type part of a command's name to hear its keys.
  • The keyboard reference lists every command with its keys.

Reading web pages

In Edge and Chrome (and Firefox, with some limits), Vox reads a page in browse mode: you move through it with the arrow keys as through a document, and single letters move by element. Down Arrow reads the next line, Ctrl+Down Arrow the next paragraph, Ctrl+Home goes to the top. Insert+Down Arrow reads from where you are to the end; any key stops it.

Vox says when you enter or leave a list, a figure, a comment, an insertion or a deletion, and calls an element "clickable" when it reacts to a click without being a link or button. Insert+Shift+I summarises the page; Insert+K says where the link under the cursor goes.

When a page opens with a cookie banner or a dialog over it, Vox says so; Insert+Shift+D presses its Reject or Close button. Vox never dismisses one by itself.

A PDF opened in Edge is read the same way. Vox says when a PDF has no headings or structure (it is "untagged") or no text at all.

Moving by element

In browse mode a letter moves to the next element of a kind, and with Shift to the previous one: H heading (1 to 6 by level), K link, D landmark, F form field, B button, E edit field, T table, L list, I list item, G graphic, and more in the keyboard reference. Insert+F7 lists the page's headings, links, landmarks, form fields, buttons and tables to pick from.

Forms and focus mode

To type in a field, move to it and press Enter, or Tab to it: Vox switches to focus mode, where keys go to the page, and plays a sound. Escape goes back to browse mode; Insert+Space switches by hand. Vox says a field's label, whether it is required or invalid, and its error message. Web applications such as editors, chat and mail apps start in focus mode.

Tables

In a table, Ctrl+Alt+Arrow keys move cell by cell, saying the row and column headers when they change. Ctrl+Alt+Home and Ctrl+Alt+End go to the first and last cell. For a table without headers, you can set the row or column that holds them.

Find, select and copy

Insert+Ctrl+F finds text on the page; Insert+F3 finds the next match. In browse mode, Shift with the arrow keys selects text and Ctrl+C copies it.

Applications and documents

In applications Vox says what has focus as you move with Tab and the arrow keys, reads text as you type and move the caret, and reports progress bars. Insert+Tab says what has focus, Insert+T the window title, Insert+End the status bar, Insert+F12 the time.

Reviewing the screen

The review cursor reads text anywhere on the screen without moving the focus, and object navigation moves between the controls of a window. See the Object navigation and Review cursor sections of the keyboard reference.

Reading text in pictures

Insert+R recognises the text of the navigator object (while browsing, the graphic at the cursor, or else the page as shown, such as a scanned PDF) and reads it; Insert+Ctrl+R recognises the whole window. The review keys then read the recognised text again, and Insert+Ctrl+Enter clicks the word the review cursor is on. Text is recognised on your computer by Windows; nothing is sent anywhere. Windows needs the optical character recognition feature of your language (Settings, Time and language, Language and region).

Describing pictures and summarising pages (AI)

Insert+G describes the navigator object (while browsing, the graphic at the cursor, or else the page as shown); Insert+Alt+G asks a question about the window in front, such as "how do I attach a file?". In browse mode Insert+Ctrl+I summarises the page and Insert+Ctrl+M moves to where its main content starts (press again for the next suggestion). Answers are spoken and can be read again with the review keys. Press the same key again, or Ctrl, to cancel.

These need an AI model: one on your computer (Ollama), or Claude with your own API key (Vox menu, Set AI provider key). Nothing is sent off your computer without your say-so: Vox asks the first time in each session (AI settings page), and never sends password fields, the windows of password managers, or anything from the sign-in screens. Without AI, the page summary comes from the page's headings and text. When a page has a CAPTCHA, Vox says so and how to get past it accessibly (an audio challenge or accessibility option); it never solves CAPTCHAs.

Speech

Ctrl stops speech. Insert+Ctrl+Left and Right pick a voice setting (voice, rate, pitch, volume, punctuation, synthesizer), Insert+Ctrl+Up and Down change it. Insert+S pauses all speech until pressed again. Insert+Shift+F11 says again what Vox said a moment ago.

Math in web pages is spoken and can be explored with Insert+Alt+M when the optional MathCAT component is installed.

Braille

Vox finds a braille display by itself: HID braille displays (most displays made since 2018) plug in over USB or Bluetooth and need nothing else; older displays work through BRLTTY. The display shows the focused object with its surroundings (Remember me chk ( ), Home lnk), the line with the caret in a text field, and the line with the browse cursor on a web page. The cursor shows as dots 7 and 8, and selected text is underlined the same way. What Vox says is also shown for a few seconds.

The display's pan keys move along the line and on to the next or previous line. A routing key moves the caret or the browse cursor to that cell; pressed again on a link or button, it activates it. Type on the braille keyboard as you would on a note taker: Space with dots for arrows, Tab, Escape and Vox commands. Insert+Ctrl+T switches the display between following the focus, the review cursor, or both. The Braille tab of Settings chooses the display, the braille table (contracted or not), the cursor and how much context to show. Contracted braille needs the optional liblouis component; without it Vox shows computer braille.

Office, Teams and other applications

Vox knows some applications well and adds keys of its own while they are in front, listed in the Applications section of the keyboard reference. In Word, Insert+Alt with H, T, L, C, R or S moves to the next heading, table, list, comment, tracked change or spelling error (with Shift, the previous one), and Insert+Delete says the page, line and column. In Excel each cell is read with its titles, formula and comment marks; Insert+F2 reads the formula and Insert+Shift+C and Insert+Shift+R set the sheet's column and row titles. In Outlook the message list is read in the order you choose, Insert+Alt+1 to 6 read the header fields and Insert+Alt+8 today's appointments. PowerPoint says each new slide, Teams and Zoom say what their mute and camera keys changed, and File Explorer's details view is read with its columns. The Applications page of Settings has their options, and turns each off.

Settings and your own keys

Insert+Ctrl+G opens Settings. Every change applies at once; Cancel puts things back as they were. In Input gestures (Vox menu) you can add, change and remove the keys of any command; your keys are kept separately from the standard ones, so "Reset all to standard keys" always brings those back.

Configuration profiles

A profile is a set of settings used instead of your usual ones in an application, during Say All, or when you choose it: a faster voice in Outlook, more punctuation in Visual Studio Code, a slower rate for reading whole pages. Insert+Ctrl+P (or the Vox menu) opens the profiles: make one, then tick Use in the application that was in front, or Use during Say All, or press Activate to use it now. While a profile is in use, the settings you change go into it, so your usual settings stay as they were. Vox says the profile's name when it starts being used (an option on the General page of Settings).

Sleep mode

Some applications speak for themselves. Insert+Shift+S puts Vox to sleep for the application in front: Vox says nothing and passes every key to it, until you press Insert+Shift+S there again.

Add-ons

Add-ons teach Vox about more applications and can add speech engines and braille displays. Add-on store in the Vox menu lists the add-ons Vox's catalogue offers: type in Search to find one, then Install (or Update; Update all updates every installed add-on that has a newer version). Manage add-ons lists those installed, with what each does and its keys; it turns them off and on, removes them, and installs one from a .voxaddon file. Vox asks before installing from a file, and warns when the add-on isn't signed by a publisher it knows: add-ons run with your permissions and can read your screen, so install only add-ons you trust.

An add-on that keeps failing is turned off by Vox, which says so. If an add-on stops Vox working properly, choose Restart with add-ons disabled in the Vox menu: Vox starts again in safe mode, with no add-on loaded, so you can turn the culprit off or remove it, then choose Restart with add-ons enabled.

Remote access

A trainer or a colleague with Vox can control your computer and hear what Vox says on it. On the computer to be controlled, choose Remote access in the Vox menu and Allow this computer to be controlled: Vox says a session code and puts it on the clipboard; give it to the other person. On theirs, Remote access, Control another computer, with your computer's address (or a relay server's, when the computers can't reach each other directly) and the code. Both computers say when the session starts.

On the controlling computer Insert+F11 switches between sending your keys to the other computer and using your own; what the other computer says is spoken on yours too. Insert+Ctrl+F11 on either computer ends the session. The session is encrypted, and only someone with the code can connect.

When something goes wrong

  • If an application stops responding, Vox says so and keeps working everywhere else.
  • If Vox itself stops, it restarts on its own. If an add-on is the trouble, Restart with add-ons disabled (Vox menu) starts Vox without any.
  • Insert+F1 says details of the focused control (useful in bug reports); the speech viewer in the Vox menu shows everything Vox says.
  • Logs are in %LOCALAPPDATA%\Vox\logs (in a portable copy, the userConfig\logs folder beside Vox).
